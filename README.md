# ARM remarketing MVP prototype

A research prototype of CenterPoint ARM cases for workshop review. It is not Recovery HQ and not production CenterPoint.
Sample values are illustrative. A favorable review of this prototype is not a product decision or a release.

Open a release: `mvp-coming-soon.html` (R1), `mvp-sprint1.html` through `mvp-sprint4.html` (R2 to R5), then `mvp-v2.html` (R6, case page) and `mvp-r7.html` (R7, tentative, no date). `mvp.html` is the drawer version. A correct password opens the others too, for 30 minutes.
The prototype is stored encrypted in `assets/`. The `lucid-screens/` folder holds masked screenshots used in a design board.
